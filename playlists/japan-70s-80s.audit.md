## 4. Технічні висновки для резолвера

**`releaseDate` бреше, ISRC каже правду.** Apple віддає дату конкретного релізу,
тому цифрові перевидання показують 2007-2008 замість оригіналу. Приклад: Junko
Sakurada — Natsu ni Goyojin, `releaseDate=2007-07-18`, але ISRC `JPVI0` **`76`**
`00320` → 1976. Рік із ISRC (символи 6-7) збігся з реальним для всіх 18 треків,
де ISRC був. **Фільтр епохи має рахуватись від ISRC, не від releaseDate.**

**Шукати треба ієрогліфами, не ромаджі.** Різниця драматична:

| Запит | Збігів |
|---|---|
| `荒井由実 何もきかないで` | 5, потрібний перший |
| `Yumi Arai Nani mo Kikanaide` | **0** |
| `研ナオコ ひとり上手` | 5, потрібний перший |
| `Naoko Ken Hitori Jouzu` | 2 |

Тобто резолвер мусить спершу перекласти ромаджі в японський запис, і лише потім
шукати. Пошук напряму по вхідному рядку користувача — програшна стратегія.

**Пошук лише за назвою тягне чужих виконавців.** `夏をあきらめて` віддає Southern
All Stars (автори), `何もきかないで` віддає Lynyrd Skynyrd — «Don't Ask Me No
Questions» зіставилось через англійський переклад назви. Виконавець обов'язковий
у запиті **і** обов'язково перевіряється у відповіді.

**Один трек = багато catalog ID.** Hatsukoi у Kozo Murashita знайшовся під шістьма
різними ID (різні збірки й перевидання). Потрібне правило вибору: пріоритет
оригінальному альбому, а не першому збігу.

### Поправки до аналізу, знайдені під час виконання

**Subaru — не 1980.** ISRC `JPPO01700853` → 2017, альбом «Standard ~best value
selection~». Це перезапис. Оригінального запису 1980 року в каталозі немає взагалі;
найраніший доступний — сингл `943351240` (1988), його й поставлено. Тобто
«у періоді» насправді 8 треків із 21, не 9.

**Сторфронт.** Налаштування кажуть `us`, реальний — `pt`. У `us` три треки дають
404 (Mayonaka no Bossa Nova ×2, Subaru). Резолвер мусить брати сторфронт
користувача, а не константу.

**Bossa Nova — дублікат доведено.** Обидві позиції мають ISRC `JPTO01100803` при
різних каталожних ID (`720570717`, `715661147`) і різному написанні виконавців.
Тільки ISRC це ловить.

**Дати в еталоні були неточні:** Hitori Jouzu — 1981, не 1980; Nani mo Kikanaide —
1975 (альбом «Cobalt Hour»), не 1974.

### Помилка реалізації, варта запам'ятовування

`create_playlist` повертає ID створеного плейліста одразу, але скрипт його
проігнорував і шукав плейліст за назвою — індекс бібліотеки ще не встиг
оновитись, пошук провалився. Захист спрацював правильно: оригінал не чіпався,
поки нові плейлісти не були підтверджені. **Правило для CLI: використовувати
повернутий ID, ніколи не шукати щойно створений об'єкт за назвою.**
